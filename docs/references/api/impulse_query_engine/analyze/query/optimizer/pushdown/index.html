Building blocks of Spark pushdown rules.

check_name​

def check_name(kind: str, name: str) -> str

Return name if it is a valid rule, rule column or run name, else raise.

Names are lowercase letters, digits and single underscores, starting with a letter. Pipeline columns join them with __, which a name never contains, so names of different rules cannot collide.

Pushdown​

class Pushdown()

A subtree that a :class:PushdownRule computes natively in Spark.

Expression nodes overload ==, so pushdowns compare by identity; use :attr:variant_key to identify equivalent pushdowns.

A pushdown reads the samples of its channel, possibly absorbing pushed operands into that pass, or computes on the result of another pushdown, its :attr:source. The pipeline computes the former only.

Arguments:

  • rule (PushdownRule): The rule that matched the subtree.
  • selector (TimeSeriesSelector): The physical channel selector the subtree reads.
  • params (tuple of (str, Any)): Canonical, hashable operation parameters (e.g. (("sample_rate", 1e6),)).
  • consumed (tuple of TimeSeriesSelector): Every selector occurrence inside the subtree (its get_selectors()).
  • source (Pushdown): The pushdown whose result this one computes on; None when it reads the channel's samples.

variant_key​

def variant_key() -> tuple

Identity of the derived series, independent of the input channel.

Operand​

Classification of an operand of the node a rule matches: the selector of a

PushdownRule​

class PushdownRule(abc.ABC)

Recognizes a subtree and computes it in Spark ahead of the pandas UDF.

Planning and decoding run in Python: :meth:match recognizes a node on the driver from its operands' classification; :meth:decode builds, in the UDF, the object the subtree evaluates to from its variant's derived rows. The result must equal evaluating the subtree in pandas on the same channel data. Only built-in rules can be decoded in the UDF (:func:~.query_optimizer.builtin_rules).

The Spark side is a set of hooks returning columns, evaluated by the shared pushdown pipeline (:mod:.pipeline) for the samples of the rule's variants, one series (channel and variant) at a time, with a :class:SeriesContext:

  1. :meth:row_columns per sample;
  2. :meth:keep selects the samples that go on;
  3. :meth:kept_columns per kept sample;
  4. :meth:emit the derived rows of a kept sample.

Rules never handle DataFrames, so every rule shares the pipeline's reads and shuffles. Derived rows have the channel-data shape (container_id, channel_id, variant, tstart, tend, value).

name​

Unique rule name, part of every :attr:Pushdown.variant_key; lowercase

letters, digits and single underscores (see :func:check_name).

ordered​

Whether the rule needs its series in order (neighbours, runs, series

facts). Per-sample rules set False and skip the series scan.

match​

def match(node: TimeSeriesExpression, operand: Operand) -> Pushdown | None

Return the pushdown for node, or None if the rule does not apply.

Nodes are classified bottom-up: operand returns the classification of any operand of node. A pushdown reading the channel's samples sets no source; when it absorbs a pushed operand into that pass, its consumed includes the operand's and :meth:supports covers both. A pushdown computing on a pushed operand's result sets source to it.

row_columns​

def row_columns(ctx: SeriesContext) -> Mapping[str, Column]

Columns computed for every sample, in order; refer to them via ctx.col.

Column names follow :func:check_name and only need to be unique within the rule.

keep​

def keep(ctx: SeriesContext) -> Column

Whether a sample can emit rows; the others are dropped early.

kept_columns​

def kept_columns(ctx: SeriesContext) -> Mapping[str, Column]

Columns computed for the kept samples, in order (ctx.block_end available).

emit​

def emit(ctx: SeriesContext) -> Column

The derived rows of a kept sample.

Returns:

Column: An array of :data:~.context.ELEMENT_TYPE structs built with :meth:SeriesContext.element; empty or null emits nothing. Times left out keep the sample's own tstart / tend.

decode​

def decode(pushed: PushedNode, cache: TimeSeriesCache) -> Any

Build a pushed-down node's result in the UDF from its variant's derived rows.

selector.build(cache, variant=pushed.variant) loads them like raw rows. Only called when each selector's channel has derived rows in the container; otherwise the node is evaluated normally.

emits_result_rows​

def emits_result_rows(pushdown: Pushdown) -> bool

Whether pushdown's derived rows are its result's samples as they are.

True only if :meth:decode returns them unchanged as a :class:SampleSeries (apart from the alias conversion factor). Calculated channels that are such a pushdown as a whole are then emitted from Spark, without :meth:decode.
